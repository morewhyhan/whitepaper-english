# 关联辅助与词库数据：技术选型备忘

> 状态：研究记录。核心决定已于 2026-11-08 接受，见 [ADR-0005](./adr/0005-association-pipeline.md)。
> 日期：2026-11-08
> 关联需求：[词汇规格](../features/vocabulary.md)、[2026-11-04 PRD 摘录](./inputs/20261104-vocabulary-prd.md)

## 1. 要解决的问题

1:8 关联网络要求：真实性优先；按来源分层补满 8 个；离线预计算；内置词书随应用分发；自定义词书走同一管线。围绕这条主线，还没定的技术细节集中在六块：语义向量、候选选择、句子生成、校验、数据分发、词义与发音数据。

## 2. 已确认约束

- 一组是 1 个目标词、8 个外围词、8 句英文。句子必须同时包含两个词，允许词形变化，优先 4 到 9 个词。
- 来源优先级：当前词书里会的词、当前词书其他词、其他词书里会的词、通用词。
- 关联页只读，不判定。
- 前台只读缓存，不现场调用模型。
- 内置词书离线生成，自定义词书导入时同管线。
- Web 端优先，当前不做服务端账户。

## 3. 管线总览

    ECDICT 词形/释义/词频
            |
    词条清洗 + 义项锚点（原句或首选释义）
            |
    句向量（词 + 义项锚点）→ 15k 词向量矩阵
            |
    每目标词 top-K 候选（K=24）
            |
    按词书层级筛选 → 语义排序 → 关系多样性
            |
    句子生成（LLM 批量）
            |
    校验（词形、语法、语义、长度、重复）
            |
    静态 JSON 分片 + 索引 → 前端按页加载

## 5. 语义向量

### 5.1 粒度

- 词形向量：一个词一个向量，最快，但 bank、charge 这类多义词会混。
- 义项向量：每个义项一个向量，需要义项清单，质量最好但工程量大。
- 原句上下文向量：把「词 + 该书原句」编码成一个向量。原句已经给出语境，能天然区分义项，工程量最小。

推荐第三种。没有原句的词，用 ECDICT 的首选中文释义拼一个短上下文。两者都没有时退回词形向量。

### 5.2 模型

- 托管 API（OpenAI text-embedding-3-small、Cohere Embed）：1536 或 1024 维，质量稳定，按 token 计费，需要网络和密钥，词表会离开本机。
- BGE-M3：1024 维，多语言，约 2 GB，质量好，适合自建服务，不适合浏览器。
- bge-small-en-v1.5 或 all-MiniLM-L6-v2：384 维，约 30 到 100 MB，本地 CPU 可跑，英文足够。
- 静态词向量（GloVe、fastText）：最小，但无语境，不推荐做主方案。

推荐 bge-small-en-v1.5，只在构建期使用，前端不加载模型。英文词表不需要多语言模型。

### 5.3 索引

15k 词乘 384 维 float32 约 23 MB，构建期做精确余弦即可，一次几秒。前端不查向量库，只读预先算好的邻居列表。sqlite-vec 适合自定义词书在浏览器里做大索引，但不是第一版必需。

### 5.4 多义与词形

- 用 ECDICT 的 exchange 字段还原 lemma，处理 apples、went 这类变形。
- 同形不同义按原句义项分开；没有原句时合并，并在显示上只给首选释义。
- 短语（make up one's mind）不做 lemma 还原，按原样匹配。

## 6. 候选选择

1. 对目标词取 top-K（K=24）语义邻居。
2. 按层级过滤：当前词书会词、当前词书其他词、其他词书会词、通用词。
3. 层级内按余弦排序，再用贪心保证关系类型分散，避免 8 个近义词扎堆。
4. 过滤与目标词义项冲突、词性明显不搭、无法写出自然句子的候选。
5. 补满 8 个；仍不足时显示空态并允许返回扫词。

关系类型标签可由生成阶段顺带产出：属性、动作、因果、场景、文化。没有标签时按词性和搭配粗分。

## 7. 句子生成

### 7.1 方案对比

- **LLM 批量生成**：覆盖全，句式自然，可按关系定制；需要提示词、评审和成本。
- **语料检索**：从 Tatoeba 等找同时含两词的句子，真实但覆盖低，长短不一，未必适合学习。
- **模板生成**：便宜可控，但句子僵硬，容易八句一个句式。
- **混合**：先检索，命中就用真句；没有命中再让 LLM 写，最后统一校验。

推荐混合，第一版可以只用 LLM 加校验，检索作为后续质量增强。

### 7.2 生成约束

- 每句 4 到 9 个英文词，只用一个简单句或一个短复合句。
- 必须同时出现目标词和外围词，允许屈折变化。
- 不使用专有名词、争议事实和需要外部知识的文化断言。
- 8 句尽量不同句式，不重复「X is Y」。
- 批量请求，每批 20 对，温度 0.3 左右，输出结构化 JSON。

### 7.3 成本估算

3,975 个目标词乘 24 个候选约 95,000 对。按每批 20 对，约 4,800 次请求。每对约 100 输入 token 加 40 输出 token，总计约 1,300 万 token。按便宜模型估算，生成加评审大约几美元到几十美元，取决于供应商和重试率。这个数字是量级估算，不是报价。

## 8. 校验

1. **词形**：ECDICT exchange 加简单词形还原，确认两个词都以原形或屈折形式出现。
2. **语法**：LanguageTool 自建服务或 CLI 批量检查；Harper 是 Apache-2.0 的 Rust 检查器，可离线跑，适合作为第二道。
3. **语义**：NLI 小模型或第二个 LLM 判断句子是否真的表达两个词的关系；明显错误直接丢弃。
4. **结构**：长度、重复、句式为空的硬规则。
5. **人工**：首批 200 组人工打分，之后每批抽 50 组；保留用户举报入口。

失败处理：同一对最多重生成 2 次，仍失败就换候选；整组不足 8 个时按 D7 处理。

## 9. 数据打包与分发

单条记录：

    {
      "target": "apple",
      "sense": "fruit",
      "links": [
        {"word": "tree", "sentence": "Apples grow on trees.", "relation": "location", "tier": 1}
      ],
      "generator": "assoc-v1",
      "validated": true
    }

- 95,000 条约 10 到 12 MB 原始 JSON，gzip 后约 3 到 4 MB。
- 按词书和首字母分片，每片几百 KB。
- 前端按当前页 36 个目标加载，单页约 10 KB gzip。
- 自定义词书结果存 IndexedDB，结构相同。
- 生成器版本和内容指纹写入每条记录，便于回滚。

## 10. 自定义词书

- 导入时在本地算向量：transformers.js 加载 bge-small，几千词在浏览器里可接受，但首次要下载模型。
- 句子生成不能在浏览器里跑大模型。选项：服务端批量任务、用户等待后台生成、或者自定义词书暂不提供关联。
- 推荐第一版只给内置和预置词书提供完整关联；自定义词书先给「语义邻居 + 暂无句子」的占位，等服务端任务跑完再补齐。

## 11. 释义与词形：ECDICT

- ECDICT 是 MIT 许可的英汉词典库，含中文释义、音标、词频、四六级等考试标签、动词变位和派生词。
- 字段包括 word、phonetic、definition、translation、pos、collins、oxford、tag、bnc、frq、exchange。
- 可以直接解决三件事：中文释义、lemma 还原、预置词书（按 tag 生成四级、六级、考研等词表）。
- 需要先跑覆盖核对：3,975 个词里有多少能在 ECDICT 命中，命中的释义是否适合四级和专升本难度。
- 显示时去掉词性前缀和重复括注，保留原始字段。

## 12. 发音

- Web Speech API：免费、即时、无需音频文件；音色和可用性取决于系统，部分环境没有 en-US 声音。
- 预生成音频：音色统一，可离线；4,000 个词约 40 到 80 MB，需要 TTS 服务和托管。
- 词典音频接口：覆盖和许可不稳定，不建议作为唯一来源。

推荐第一版用 Web Speech，代码里做声音可用性检测和英文声音选择；如果真实使用中音色问题明显，再为内置词书预生成音频。

## 13. 质量与评估

- 覆盖率：有 8 条合格关联的目标词占比。
- 语法通过率：LanguageTool 和评审都通过的句子占比。
- 人工评分：200 组抽样，按真实、自然、有助记忆三项打分。
- 用户举报率：关联页提供「这条不好」入口，按周统计。
- 加载性能：单页关联数据加载低于 300 毫秒。

## 14. 推荐组合

- 词义与词形：ECDICT。
- 向量：bge-small-en-v1.5，构建期批量，原句上下文编码。
- 索引：构建期精确余弦，前端只读邻居列表。
- 候选：预置词书并集加前 2 万高频词，K=24。
- 句子：LLM 批量生成，便宜模型写、另一个模型评审，LanguageTool 查语法。
- 分发：按词书和首字母分片 JSON，按页加载。
- 自定义词书：本地向量，句子走后台任务；未完成时明确显示。
- 发音：Web Speech 先行。

## 15. 已决定（2026-11-08）

1. 向量走本地开源，bge-small-en-v1.5，只在构建期使用。
2. 第一版内置词书和自定义词书都提供完整 1:8；自定义词书走后台生成任务。
3. 预置词书按词频分层生成，考试标签只作为词条元数据。
4. 生成不设硬预算，由智能体批量完成，再按抽检控制质量。
5. 发音先用系统语音，效果不足再预生成音频。
