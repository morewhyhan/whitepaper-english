# ADR-0006 只保留背单词，移除写作与语法模块

## 状态

已接受（2026-11-10）。取代 ADR-0005 中关于写作/语法入口的开放性假设。

## 背景

产品曾保留“写作”和“学语法”两个未开放入口，并尝试把 English G Mastery 接成第三阶段的语法机制课程。实际判断后，用户决定收窄产品：白纸英语只做背单词，不再把写作或语法作为同一工作台里的并列模块。

约束来自当前真实使用：词汇纸已经形成完整闭环（扫词、判定、关联、清零），写作和语法都需要独立的内容、交互与验证体系，混在同一外壳里会分散注意力和开发资源。

## 决策

1. **产品只保留背单词。** 顶部不再提供“写作”“学语法”入口，页面只承载词汇纸。
2. **删除写作/语法的产品目标。** GOAL 中的语法领域、三个 tab、未开放模块 AC 和对应 Feature 一并移除。
3. **删除占位实现与测试。** 不保留“暂未开放”的假入口，避免把未实现能力展示成产品的一部分。
4. **保留纸张外壳。** 词汇页的视觉、导航、设置、词书和发音继续使用现有白纸语言；本次只砍模块，不改词汇交互。
5. **写作/语法未来如重启，必须是独立产品决策。** 需要新的 GOAL、独立内容来源、交互验证和退出条件，不能靠恢复旧 tab 悄悄回来。

## 替代方案

- **保留“暂未开放”占位**：否决。占位会持续制造“即将有”的预期，也增加导航和测试负担。
- **把语法做成独立子应用**：暂不采纳。当前没有独立内容、AI 判题和成本模型；先不启动。
- **只删 UI、保留文档和测试**：否决。死文档和死测试会误导后续开发，必须同批清理。
- **保留三 tab 但禁用**：否决。与“只做背单词”的范围冲突，也会让顶部导航不稳定。

## 代价与风险

- 已写好的语法目标、Feature、测试骨架和克隆内容不会进入产品；相关投入暂时沉没。
- 如果未来重启语法，需要重新审计 English G Mastery 的内容、许可、AI 成本和交互，不能直接复用旧 GOAL。
- 写作入口消失后，用户不能在同一产品里写自由文本；这是明确的范围取舍。

## 影响

- docs/GOAL.md 回到单词单一目标，删除语法领域和写作/语法相关 AC。
- 删除 docs/features/grammar.md、docs/features/writing.md、语法测试和未开放模块测试。
- vocabulary-screen.tsx 移除 WorkspaceMode、模块 tab 和 UnavailableModule。
- 现有词书、判定、关联、音频、账户和视觉测试保持通过。

## 复审条件

- 用户明确要求把写作或语法作为独立产品重新立项。
- 词汇闭环出现无法在单一模块内解决的需求。
- 当前导航或页面结构因移除模块产生实际可用性回归。

## 复审记录

2026-11-10：用户决定只做背单词，首次接受。
