# 2026-11-08 核心需求输入

来源：用户在当前会话中直接提出的六项核心问题。本页保留原话要点和处理去向，不改写用户原意。本页只证明来源，不是产品规格。

## 原话要点

1. 顶栏布局不符合 Next.js 规范。背单词、写作、学语法切换时，页面顶部的 Bar 会整体换掉，不像共用同一个布局。
2. 学习进度要能跨访问保留。今天背到第二轮某一页的某个词，下一次进入还应该停在那个位置。
3. 要保留每天、每一轮的数据：会多少、不会多少、总数多少，并能用一个更舒适的统计界面展示。
4. 单词缺少中文翻译。点“不会”标红以后，还要直接显示这个词在四级、专升本难度下的常见中文意思。
5. 单词需要发音，要求美式发音。
6. 整体使用体感需要优化，包括音效和点击反馈，可以作为独立模块；发音也可以归入这个模块。
7. 关联辅助模式目前基本没有内容。

## 处理去向

- 第 1 项写入 [架构标准](../../standards/architecture.md) 的前端外壳与路由规则，以及 [工作台规格](../../features/workspace.md) 的外壳章节。
- 第 2、3 项写入 [词汇规格](../../features/vocabulary.md) 的学习进度与学习统计章节。
- 第 4 项写入词汇规格的释义章节，前置条件是确定释义数据源与许可。
- 第 5 项写入词汇规格的发音章节，当前候选实现是浏览器 en-US 语音合成。
- 第 6 项写入工作台规格的交互反馈章节。
- 第 7 项写入词汇规格的关联辅助章节。

以上条目尚未分配 REQ/AC。按仓库检查规则，每条 AC 必须有同名自动化测试；进入实现 Plan 时再转成可执行验收并补测试。
