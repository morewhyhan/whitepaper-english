# 词义语境来源与覆盖（2026-11-08）

本页记录给 3,975 条词书补中文释义、判断多义词义项的材料来源、覆盖率和版权边界。它是数据来源记录，不是产品规格。

## 来源

### 1. 新概念英语逐句文本

- 仓库：https://github.com/hoothin/NCE
- 内容：四册共 276 个 LRC 文件，6,041 句，英文和中文逐句对照，带时间轴。
- 解析方式：每行形如 `[00:17.43]English sentence|中文翻译`，去掉时间轴后按竖线拆分。
- 许可：仓库声明 MIT，但 MIT 覆盖的是仓库代码和整理工作，不覆盖《新概念英语》教材正文的著作权。教材正文的权利仍属于原作者和出版方。

### 2. 三份平行世界阅读

- 英语的平行世界初级阅读.pdf，50 页。
- 中级阅读付费版.pdf，31 页。
- 高级阅读讲义.pdf，47 页。
- 合计约 4.2 万词，约 128 篇阅读，含题目。部分难词在正文里带中文括注，例如 `barrel（桶）`、`sledder（驾雪橇者）`。
- 许可：用户购买的付费材料，不能随产品再分发。

### 3. ECDICT

- MIT 许可的英汉词典库，提供释义、音标、词频、考试标签和词形变化。
- 用于兜底释义、lemma 还原和预置词书分层。

## 覆盖率

以 `src/modules/vocabulary/data/parallel-world.json` 的 3,975 条词条为基数，清洗词性标注、括号和编号后得到 3,866 个唯一词形：

- 在新概念或三份阅读中至少出现一次：3,470 个，约 89.8%。
- 未命中：396 个。多数不是真正的生僻词，而是短语、连字符词、变形和录入噪声，例如 `take out`、`turn on`、`writing-paper`、`smelt`、`arica`、`in insight`。
- 加上短语匹配和 ECDICT 的 lemma 还原后，覆盖率还会上升。剩余缺口用 ECDICT 释义兜底。

## 义项选择方法

1. 对每个词条取清洗后的词形。
2. 在新概念 LRC 里找出包含该词的句子，得到英文句和中文翻译。
3. 把 ECDICT 的中文释义按分号拆成候选义项，和中译文比对，命中的义项记一票。
4. 平行世界阅读里优先使用正文自带的中文括注；没有括注时用所在段落的上下文。
5. 同一词在两类材料里义项冲突时，按优先级取：新概念原文、平行世界阅读、ECDICT 常用义。
6. 没有任何语境证据时用 ECDICT 首选义；仍然缺失就显示空释义，不编造。

## 版权边界

- 新概念正文和付费阅读都不能复制进产品界面，也不能随数据包分发。
- 这些材料只用于内部判断词义和义项，不作为关联句的直接来源。
- 关联辅助的英文句子优先自己生成；如果确实要复用原文句子，必须先取得授权，否则改写。
- 生成结果只保留句子和词对，不保留原文段落。
