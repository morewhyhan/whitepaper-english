# 统一学习工作台规格

## 背景与目标

工作台是白纸英语的共同外壳。它让用户从词汇、写作或语法任一活动开始，保留自己的输入和成果，并在需要时把一个词、一个句子或一个问题带到另一个模块。它不把不同活动压缩成一条课程闸门，也不把三种证据合并成单一掌握分数。

## 第一阶段采用决策

- 首屏第一入口是词汇白纸，直接进入学习动作。
- 游客拥有完整的第一阶段本地路径：输入、导入、判断、轮次恢复和导出。
- 登录是可选同步边界；登录前后的本地数据归属、冲突解决和跨设备合并需要在同步实现 Plan 中按“本地副本优先、明确确认后合并”执行，不静默覆盖。
- 写作和语法显示为工作台页面外壳，但标记为暂未开放；它们的实际功能不在当前阶段导航中伪装成可用。
- 工作台采用纸张堆叠的视觉隐喻；当前只展示一张活动纸，纸张属于词汇、写作或语法中的一个模式。

## 模块边界

| 模块 | 工作台提供                     | 模块自己负责                     |
| ---- | ------------------------------ | -------------------------------- |
| 词汇 | 入口、保存、导出、账户同步边界 | 词表、轮次、自评和困难词上下文   |
| 写作 | 原文归属、版本引用、导出       | 原文编辑、建议、应用/忽略/撤销   |
| 语法 | 作答与总结归属、跨模块引用     | 机制问题、提示、复验和用户确认   |
| 认证 | session、账户和授权边界        | 不决定用户能否第一次开始本地学习 |

## 工作台外壳（2026-11-08 确认，待立 AC）

顶栏、模块标签、纸张背景和全局操作组成工作台外壳，由路由 layout 提供，全站只有一个实例。规则见[架构标准](../standards/architecture.md)的 STD-ARCH-102。

- 背单词、写作和语法各有地址。标签是链接，不是组件内状态。
- 切换模块时，顶栏的位置、尺寸、品牌和全局操作保持不动。
- 模块专属操作（词书、禅模式、导入导出）放在当前模块的内容区，不占用全局顶栏的固定位置。
- 直接打开某个模块地址、刷新、前进和后退都能到达同一状态。
- 切换模块不重建词汇进度。回来后仍在原来的轮次和位置。
- 未开放模块保留完整外壳，内容区显示未开放状态。

本轮确认来源见[2026-11-08 需求输入](../others/inputs/20261108-core-requirements.md)。

## 领域概念

| 概念     | 含义                               | 所有权与状态                     |
| -------- | ---------------------------------- | -------------------------------- |
| 内容     | 用户输入的词、句子、问题、笔记     | 用户拥有，可编辑、可导出         |
| 上下文   | 被另一个模块引用的词条、原句或问题 | 保留来源，不复制成互相矛盾的事实 |
| 成果     | 用户自评、原文版本、确认后的总结   | 标记来源和确认状态               |
| 本地副本 | 未登录时的可用学习数据             | 先保存到当前设备，失败要提示     |
| 账户副本 | 登录后的同步数据                   | 由当前用户拥有，不能跨用户读取   |

## 业务规则

当前阶段只记录以下已开放工作台规则。

- R1（REQ-WORKSPACE-001）：用户可从词汇、写作或语法活动进入，不以完成另一个模块作为强制前置；第一阶段只开放词汇实际入口。
- R2（REQ-WORKSPACE-006）：工作台以纸张堆叠组织多个学习上下文；用户切换活动纸时，当前纸只承载一个模块和一个学习任务，不把不同模块内容纵向拼接；未开放模块只显示页面外壳和状态。

## 验收标准

- AC-WORKSPACE-001（REQ-WORKSPACE-001）：Given 用户未完成词汇活动，When 查看写作或语法入口，Then 不因词汇未完成被页面状态阻止。
- AC-WORKSPACE-006（REQ-WORKSPACE-006）：Given 用户打开词汇、写作或语法中的工作台纸张，When 用户切换活动纸，Then 新纸张只展示自己的模块内容，未开放模块明确显示状态，词汇纸的输入和进度仍可返回。

## 设置（2026-11-08 确认，待立 AC）

- 设置以独立的大面板出现，不再是窄弹窗。桌面宽度至少 960px 或 80% 视口，高度至少 70% 视口。窄屏全屏。
- 桌面分两栏：左侧是分类列表，右侧是当前分类的设置项。点左侧切换右侧，不跳转页面。
- 分类至少包含账户、学习记录、发音与声音、判定与操作、词书与数据、外观。
- 首次打开停在账户分类。之后打开回到上次查看的分类。
- 左侧选中项用文字、图标和状态表达，不能只靠颜色。右侧独立滚动，左侧不跟着滚。
- 窄屏改为列表优先：点分类进入详情，返回回到列表，不并排挤成两栏。
- 关闭设置回到原来的纸和位置，未提交的点击不丢。
- 设置项修改立即生效并保存，不需要“保存”按钮。
- 账户分类显示当前身份。未登录时显示访客状态和“数据只保存在本机”，不伪造用户名。登录入口在账户接入后放进这里。

## 交互反馈（2026-11-08 确认，待立 AC）

- 判定、翻页和切换模块在 100 毫秒内出现视觉反馈。用户不用等动画结束才知道结果。
- 判定和翻页播放轻音效，默认开启，设置里可以关闭。
- 静音时功能、状态和可访问名称保持完整。反馈不只靠声音。
- 发音和音效共用一个音频通道，同一时刻只播放一个声音。
- 首次进入页面不自动播放声音，避免浏览器拦截和打扰。
- 反馈不改变判定语义，也不延迟保存进度。

## 后续阶段目标

以下内容是账户同步和跨模块协作开放后的产品方向，当前不作为已开放功能的 REQ、AC 或 Plan 约束：

- 跨模块引用保留原文、来源模块和必要版本，不让 AI 整理覆盖用户原话。
- 登录增加账户保存、同步和恢复，不改变学习内容所有权。
- 保存失败、导入失败或同步冲突必须保留当前输入，并给出恢复、重试或导出的明确选择。
- AI 不可用时，输入、编辑、判断、导出等基础动作仍可继续。

## 非目标与后续决策

本阶段不做 PWA、离线跨设备同步、自动冲突合并、统一掌握分数或 AI 服务。同步冲突、版本恢复粒度和跨模块引用展示在进入对应实现阶段前写入独立 Plan。
