# 词汇工作台规格

关联需求：REQ-WHITEPAPER-005

## 背景与目标

工作台只承载背单词这一张纸。它负责词汇页的外壳、导航、设置、词书入口和账户边界，不把写作、语法或其他学习活动拼进同一张纸。

2026-11-10 决定移除写作和语法模块，记录见 [ADR-0006](../others/adr/0006-vocabulary-only.md)。

## 外壳

- 首屏直接进入词汇白纸。
- 顶部只有品牌、词书、禅模式、登录/退出和设置，没有模块 tab。
- 不出现“写作”“学语法”或“暂未开放”的入口。
- 词书、禅模式和设置属于词汇纸；切换不重建词汇进度。
- 工作台采用单张纸张视觉，不再使用“纸张属于某个模块”的多模式导航。

## 模块边界

| 模块 | 工作台提供 | 模块自己负责 |
| ---- | ---------- | ------------ |
| 词汇 | 入口、保存、导出、账户同步边界 | 词表、轮次、自评、关联和困难词 |
| 认证 | session、账户和授权边界 | 不决定用户能否第一次开始本地学习 |

写作和语法不属于本工作台。未来如重启，必须作为独立产品决策另立目标与验收。

## 设置

- 设置以独立大面板出现，桌面约 980×730，使用白纸视觉。
- 桌面分两栏：左侧编号分类，右侧当前分类内容。分类为账户、学习记录、发音与声音、判定与操作、词书与数据、外观。
- 左侧选中项同时用底色、编号和文字表达，不只靠颜色。右侧独立滚动。
- 关闭设置回到原来的纸和位置。
- 词书与数据显示当前词书；重置今天二次确认后回到第 1 页并提示“今日进度已清零”。
- 不提供导入、导出和清空全部。
- 外观只说明当前使用纸张浅色主题。

## 交互反馈

- 判定、翻页在 100 毫秒内出现视觉反馈。
- 判定和翻页播放短促轻音效，设置里可关闭。
- 静音时状态和可访问名称完整，反馈不只靠声音。
- 发音和音效共用一个音频通道，同一时刻只播放一个声音。
- 首次进入页面不自动播放声音。

## 验收标准

- AC-WHITEPAPER-005（REQ-WHITEPAPER-005）：Given 产品入口，When 访问首页和工作台，Then 第一动作是进入词汇白纸，顶部没有写作、学语法或“暂未开放”的假入口。
