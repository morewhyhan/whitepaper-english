# 词汇白纸规格

## 背景与目标

词汇白纸来自用户提出的 A4 白纸式扫词、多轮筛选和关联辅助。目标不是让用户重复浏览一个词表，而是让用户迅速完成一次真实自评：先看词，直接判断会不会，再把不会的词收进下一轮。

## 产品原则（2026-11-08 确认）

- 词汇、禅模式、书架、关联辅助、发音和学习记录都是学习英语的必要不充分条件。它们不因为“功能多”被删除，只因为与当前阶段冲突才延期。
- 不做的只有非必要项：打卡、排行、社交、连续天数和掌握率。
- 设计工作不是删功能，而是降低每个功能的摩擦：合理默认、一步进入、不让用户配置本该由产品决定的事。
- 用完即走：用户不需要维护任何东西，关闭页面不弹确认。

## 第一阶段采用决策

- 首屏显示一张完整的 A4 扫词纸和一组词。产品不以某个固定屏幕宽高为前提；在用户打开产品的屏幕尺寸上，纸张上的全部词条必须在一个视口内从上到下可见，用户无需滚动、拆页或展开才能扫完。
- 每个词同时显示英文和可选释义；判断按钮明确写“会”和“不会”。浅绿/浅红只做辅助，不能是唯一状态表达。
- 默认点击按按钮文字判断；若后续提供键盘快捷键，普通键和 Shift 反向判断必须在设置中说明，触屏必须有等价按钮。
- 一轮结束后只把“不会”的词带入下一轮；全部判断为“会”才完成本次自评。未判断不等于“会”。
- 当前阶段不提供导入和导出入口。词书使用内置和预置；已有导入解析和导出代码作为历史能力保留，不进入第一版界面。
- 账号是数据归属。登录后学习数据保存在账号数据库；未登录仍可在本机学习，数据只在本机，登录时可以选择并入账号。
- 2026-11-08 用户决定：当前验收只覆盖 Web 端（桌面浏览器）；移动端浏览器验收和布局修复暂缓，不作为本轮完成条件。窄屏可读性规则继续有效，恢复移动端工作时重新纳入验收。
- 导入和导出能力已在历史实现中存在，当前阶段不提供界面入口。R7、R8 以及 AC-VOCABULARY-007、AC-VOCABULARY-008 保留为历史能力，不进入第一版验收口径。

## 核心学习循环（2026-11-04 PRD 基线，待立 AC）

来源见 [2026-11-04 PRD 摘录](../others/inputs/20261104-vocabulary-prd.md)。

- 每天以完整目标词库开始第一轮，初始目标约 4000 词。每日目标量可以配置，默认使用当前词书全部词条。
- 后续轮次只扫描上一轮不会的词，直到错词池为零。
- 全量首轮覆盖所有目标词，且最终错词池为零，才显示“今日通关”。暂停不等于完成。
- 第二天重新建立完整首轮。昨天未完成的记录保留为未完成，不标记通关。
- 每页默认 4 组 3×3，共 36 个词位。尾页不够时按实际数量渲染。
- 常规九宫格每轮重新随机排词。
- 普通点击和 Shift 点击的判定含义可以互换。默认普通点击标“不会”。未点击的词在翻页时按当页模式计入。
- 标为“不会”的词立即显示中文，格子位置不移动。
- 点“下一页”提交本页并推进。回到上一页会清空该页已提交的判定，只能重新判断。
- 关联辅助只帮助建立初步印象，不把目标词自动标记为会。判断回到无提示九宫格完成。

## A4 扫词纸的完整可见性

这是一条已确认的产品硬约束。A4 扫词纸指当前一次扫词所呈现的词条集合，不指把整本词书压缩到一张纸上。

- 当前纸张中的全部词条必须同时落在同一个视口内。
- 用户从纸张顶部开始，可以不滚动、不翻页、不展开，从上到下扫完整张纸。
- 屏幕变窄或变矮时，只能调整纸张缩放、字号、列数和间距；不能把同一张纸拆成多个纵向页面，也不能隐藏词条。
- 纸张可以缩放，但词条顺序和词条数量不能因屏幕尺寸改变。

本条只在本轮写入规格。当前实现通过纸张高度约束、响应式缩放和专用禅模式网格承载这条约束；仍需用代表性的窄屏、平板和桌面视口验证“整张纸一次可见”，并把验证路径写入对应 Plan。

## 多词书与纸张堆叠

词汇学习不绑定唯一词书。用户可以点选不同词书，并把每本词书理解为一摞有顺序的学习纸。不同词书拥有独立的活动纸、轮次、判断和困难词集合，切换词书只切换当前上下文，不覆盖另一摞纸的学习状态。

同一时间只有一本活动词书。拉到另一本书就是切换到那本书，不存在同时学两本。开始一本没学过的书，就是那本书新的全量首轮。

书架保持抽屉式：默认收起，悬停或点击展开，浮在页面左侧，不压缩纸张宽度。默认预置 3 到 5 本词书，按 ECDICT 词频分层生成：核心 1000、常用 3000、进阶 6000。四级、六级、考研等标签只作为词条元数据，不作为词书来源。当前阶段不新增自定义词书导入。书架只展示内置和预置词书，已有导入解析不扩展成词书管理功能。

## 禅模式

禅模式是词汇白纸的沉浸式呈现方式，不是另一套学习任务。它是顶栏常驻入口，保持置顶可见，不折叠进设置，也不藏在二级菜单里。进入后隐藏 Top 条和普通纸张堆叠，只保留当前词书、当前轮次和当前判断状态。每张禅模式纸固定使用 36 个词位，排成 6×6，并明确分成四个 3×3 九宫格；视觉上使用一张统一的 6×6 网格，四个九宫格只保留语义分组，不允许分组轨道额外撑开中间或两侧缝隙。最后一批不足 36 个词时只减少实际词条，不补造词，也不改变方格布局。词格保持正方形，纸张也必须跟随方格的实际边长保持近正方形，不能因为网格只有一行就被 CSS 拉成长条。系统根据浏览器视口计算每种列行组合的可用纸张面积，优先选择能填满视口且保持可读性的组合；在纸张大小接近时再优先多呈现纸张。高度变矮时可以减少列数，让纸张填满高度，不能为了多放一张纸留下大块上下空白。所有词格之间的横向、纵向间距必须统一，不能因为网格行高或内容溢出产生覆盖。所有纸张从原纸摞位置一次性同时抽出，不采用逐张发牌式延迟。单词或短语始终完整显示，放不下时减少同时抽出的纸张数量并增大纸张和词格，不使用界面截断省略号或隐藏文字；词库原文自带的标点必须保留。下一页按钮固定在视口右下角并保持纵向方向，Escape 或退出控件回到普通工作台。默认模式和禅模式共用纸张材质、九宫格渲染、词格组件和进场动效；会/不会/预览状态的颜色和悬停反馈也必须来自同一套词格状态规则，不能因模式切换丢失或变成中性灰色；模式差异只保留在工作台外壳和可用空间。禅模式右上角显示当前轮次和页码。

## 模块边界

词汇模块拥有词表、词条、学习任务、轮次和判断记录。工作台拥有本地/账户保存边界；关联辅助若开放，必须复用原任务、原轮次和同一困难词集合。词汇模块不负责语法掌握、写作评分或长期复习算法。

## 字段清单

| 概念     | 关键字段                           | 约束                           |
| -------- | ---------------------------------- | ------------------------------ |
| 词表     | id、名称、词条顺序、来源           | 用户可编辑；重复词需稳定处理   |
| 词条     | id、英文、释义、可选关联           | 英文非空；关联不是掌握证据     |
| 学习任务 | 词表、开始时间、当前状态           | 一个任务可有多个轮次           |
| 轮次     | 轮号、纳入词集合                   | 下一轮只来自上一轮“不会”       |
| 判断记录 | 词条、轮次、会/不会、时间          | “会”只代表本次自评             |
| 本地副本 | 当前任务、轮次、判断和设置         | 读取/写入失败须提示并保留输入  |
| 词状态   | 清洗词形、会或不会、最近判定       | 跨词书共享；不作为独立页面展示 |
| 日聚合   | 日期、目标数、首轮会、轮次数、完成 | 只用于设置里的学习记录         |

## 业务规则

- R1（REQ-VOCABULARY-001）：学习页以纸张区域呈现成组单词，用户可连续判断，桌面和窄屏都不溢出。
- R2（REQ-VOCABULARY-002）：判断状态同时通过“会/不会”文本、按钮状态和低饱和颜色表达，并可查看词义而不离开当前任务。
- R3（REQ-VOCABULARY-003）：键盘快捷键、触屏按钮和普通点击在语义上等价；Enter 始终触发下一页，不激活当前焦点的词块或按钮；输入框、选择器和弹窗内不劫持 Enter。
- R4（REQ-VOCABULARY-004）：一轮完成后只保留不会词；显示当前轮次、已判断数量和剩余困难词；没有完成所有词的任务不能标记完成。
- R5（REQ-VOCABULARY-005）：扫词和后续关联模式共享同一个任务、轮次和困难词池，返回后不重建进度。
- R6（REQ-VOCABULARY-006）：本地副本可刷新恢复；损坏、空间不足或写入失败要明确提示，不能静默创建空任务。
- R7（REQ-VOCABULARY-007）：导入支持可审查的文本格式；非法行给出可修正信息，失败导入不覆盖当前词表。
- R8（REQ-VOCABULARY-008）：导出包含词条、轮次、当前自评和日期；文案使用“本次自评”而不是“永久记住”。
- R9（REQ-VOCABULARY-009）：无论用户使用什么屏幕尺寸打开学习页，当前 A4 扫词纸中的全部词条都必须在一个视口内从上到下可见；响应式布局不得通过滚动、拆页、展开或隐藏词条来规避这一约束。
- R10（REQ-VOCABULARY-010）：用户可以在多本词书之间点选切换；每本词书保留自己的纸张顺序、学习任务、轮次和困难词集合，切换不得覆盖其他词书状态。
- R12（REQ-ACCOUNT-020）：双击九宫格任意词块或关联辅助中心词加入当前词书的垃圾桶；两边共用同一份排除表；被排除的词不再进入当前轮或之后的轮次；单击仍按原语义判定/发音，关联外围句子不归档；垃圾桶可查看并放回。
- R13（REQ-VOCABULARY-012）：只清除当前页词条的会/不会标记；不移动游标、不进入下一页、不改变其他页、轮次或垃圾桶。
- R11（REQ-VOCABULARY-011）：用户可以进入禅模式；禅模式隐藏普通工作台外壳和纸张堆叠，每张纸固定为 36 个词位的 6×6 方格，并明确分成四个 3×3 九宫格；词格和纸张都必须保持由方格决定的正方形比例，不能因网格行高被拉成长条；纸张布局优先填满可用视口面积，在纸张大小接近时再增加同时呈现的纸张数量；窄高度不得通过保留多余列数制造大块上下空白；完整单词或短语不得被界面添加的省略号截断，无法完整容纳时减少同时呈现的纸张数量并增大纸张和词格；纸张按当前视口自适应铺开并以一次性抽纸动效同时呈现；翻页按钮固定在屏幕右下角，Escape 或退出控件可以返回普通工作台。

## 验收标准

- AC-VOCABULARY-001（REQ-VOCABULARY-001）：Given 一组词表，When 未登录用户打开第一入口，Then 看到纸张区域和可读词条，不经过注册页。
- AC-VOCABULARY-002（REQ-VOCABULARY-002）：Given 一个未判断词，When 点击会或不会，Then 文字状态、按钮状态和颜色一致，并能在当前任务查看释义。
- AC-VOCABULARY-003（REQ-VOCABULARY-003）：Given 焦点在词块、按钮或页面空白处，When 按 Enter，Then 只推进下一页，焦点词块不被判定；When 焦点在输入框、选择器或弹窗内，Then Enter 保留本义。
- AC-VOCABULARY-004（REQ-VOCABULARY-004）：Given 一轮中存在不会词，When 该轮全部判断完，Then 下一轮只出现不会词；只有困难词清零才完成任务。
- AC-VOCABULARY-005（REQ-VOCABULARY-005）：Given 用户从扫词进入关联模式，When 关联模式返回扫词，Then 原任务、轮次和困难词池保持不变。
- AC-VOCABULARY-006（REQ-VOCABULARY-006）：Given 已有本地轮次，When 刷新或模拟存储失败，Then 能恢复原轮次，或保留当前输入并说明失败原因。
- AC-VOCABULARY-007（REQ-VOCABULARY-007）：Given 合法和非法导入文件，When 执行导入，Then 合法文件生成新词表，非法文件提示问题且旧词表不变。
- AC-VOCABULARY-008（REQ-VOCABULARY-008）：Given 有词表和判断记录，When 导出 JSON 或 Markdown，Then 文件可读、可重用，并包含本次自评状态和日期。
- AC-VOCABULARY-009（REQ-VOCABULARY-009）：Given 当前 A4 扫词纸包含一组词条，When 用户在窄屏、平板或桌面屏幕打开学习页，Then 这组词条从纸张顶部到底部全部位于同一个视口内，用户无需滚动、拆页、展开或隐藏词条即可扫完。
- AC-VOCABULARY-010（REQ-VOCABULARY-010）：Given 用户拥有至少两本词书且各自有学习进度，When 用户点选另一摞词书再返回原词书，Then 当前纸张只显示所选词书的词条，且两本词书的轮次和困难词集合均保持原状。
- AC-ACCOUNT-020（REQ-ACCOUNT-020）：Given 用户在当前词书看到词条，When 双击九宫格任意词块或关联辅助中心词，Then 该词进入共享垃圾桶并从当前/之后轮次排除，角标增加；单击仍判定或发音，关联外围句子不归档；When 打开垃圾桶并放回，Then 该词从排除表移除并在之后轮次恢复推送。
- AC-VOCABULARY-012（REQ-VOCABULARY-012）：Given 当前页已有会/不会标记，When 点击“本页清空”，Then 当前页所有标记清除并回到未判定状态，游标和其他页保持不变，垃圾桶也不受影响。
- AC-VOCABULARY-011（REQ-VOCABULARY-011）：Given 用户在词汇工作台打开任意词书，When 用户进入禅模式，Then Top 条和普通纸张堆叠不可见，每张呈现的纸有 36 个词位、四个 3×3 九宫格、正方形词格和不被拉长的纸张比例，单词或短语完整可见且没有界面添加的截断省略号；视口中按可读比例铺满一张或多张纸，纸张以同一批抽出动效出现，窄高度时通过减少列数避免大块上下空白，放不下时减少纸张数量而不压缩或隐藏词条，右下角可见纵向下一页按钮，按 Escape 或退出控件后恢复普通工作台。词库原文自带的标点不因验收而被删除。

## 释义（2026-11-08 确认，待立 AC）

- 中文释义放在英文上方，占词格内固定高度。未判定时隐藏，标“不会”后显示，格子不移动。排版和原型一致。
- 释义为空时显示“暂无释义”，不能只留红色。
- 释义按原文语境取义，优先级是《新概念英语》原文、平行世界三份阅读、ECDICT 常用义。多义词以原文句子表达的意思为准。
- 来源与覆盖率见[词义语境来源](../others/inputs/20261108-meaning-sources.md)。清洗后 3,470/3,866 个词形在两类材料中有语境，约 89.8%；剩余 396 个多为短语、连字符词和变形，用短语匹配、lemma 还原和 ECDICT 兜底。
- ECDICT 是 MIT 许可，提供释义、lemma 和词频。教材和付费阅读正文不复制进产品。
- 词格最多显示两行，更长时悬停或点击用气泡显示完整释义，不撑开格子。
- 显示用的词形去掉词性标记和重复括注，原始文本保留在数据里供追溯。
- 本轮确认来源见[2026-11-08 需求输入](../others/inputs/20261108-core-requirements.md)。

## 发音（2026-11-09 更新）

- 点击词条时播放一次美式英语发音，标会或标不会都播放；点击关联辅助的外围句子时朗读整句。声音是记忆的一部分，默认开启。
- 优先播放预生成的 Aria 静态音频；首次请求约 1 秒，之后由浏览器缓存。
- 静态文件缺失或播放失败时，立即用系统英文语音兜底，不阻塞判定和翻页。
- 系统兜底优先 Natural / Neural / Online / Aria / Jenny / Guy / Google US English，避开 David、eSpeak 等明显机器音。
- 不提供手动音色选择。设置只提供总开关。
- 连续点击同一内容不叠加播放；切换到另一个词或句子时停止上一段。
- 设置提供静音开关。静音后判定照常完成。
- 浏览器不支持语音合成或没有可用语音时，判定照常完成，设置页说明原因。
- 静态音频按内容哈希命名，词和句子共用同一份；前端缓存 `Audio`，鼠标移入节点会提前加载。文件缺失或加载失败时才用系统英文语音兜底。

## 学习进度（2026-11-08 确认，待立 AC）

- 登录后进度保存在账号数据库。未登录时保存在本机，登录时可以选择并入账号，不静默覆盖。
- 同一天重新打开，恢复到上次的词书、轮次、页码和判定状态。刷新或关闭标签页不丢进度。
- 跨过本地日期边界时，昨天保留为未完成记录，新的一天建立完整首轮。不做跨天续学。
- 同一时间只有一本活动词书。切换词书保留另一本的进度。
- 每天保存日聚合：日期、目标词数、首轮会、轮次数、是否完成，写进账号。
- 设置里提供“重置今天这本书”：清空今天的轮次和判定，重新开始全量首轮。历史学习记录保留。

## 学习记录（2026-11-08 确认，待立 AC）

- 学习记录是设置左侧分类里的一项，不占主导航，也不在纸面上出现。
- 一页显示当前词书的一条曲线：横轴是日期，纵轴是当天首轮识别率，也就是第一轮标为会的不同词条数除以当天目标词条数。
- 鼠标悬停或点击某一天，显示当天扫了多少词、其中会多少、不会多少、扫了几轮、有没有扫完，以及清零用时。
- 同一天只留一条。没扫完的那天也保留。
- 只按当前词书看，不跨词书合并。
- 不做单词列表，不做排行、打卡和连续天数。
- 文案使用“本次自评”，不使用“掌握”“记住”或掌握率。
- 登录后记录保存在账号；未登录只在本机。
- 没有记录时说明第一天的数据从哪来，不画空图。

## 关联辅助（2026-11-09 更新）

- 一组是 1 个目标词、8 个外围词和 8 句完整英文短句。句子只显示英文。一页只放一组 1:8，不显示箭头。
- 内置词书的 3,867 个目标词全部有 8 条关联，共 30,936 条句子。数据在 `src/modules/vocabulary/data/associations.json`。
- 关联句由离线模型/并行智能体生成，不复制《新概念英语》或平行世界阅读原文。早期设想的 bge-small 向量、24 候选和原文复用管线没有落地，不再作为当前实现描述。
- 每句 4–9 个英文词，必须同时包含目标词和外围词；允许自然屈折。合并时校验每词恰好 8 条、句长和外围词唯一，当前结构错误为 0。模型生成质量的人工抽检尚未完成。
- 前台不加载生成模型，也不现场生成；只读预计算数据。
- 服务端启动后缓存整份关联 JSON；`GET /api/vocabulary/associations?words=...` 一次返回最多 36 个词。客户端按 36 词一批读取，并在接近批尾时预取下一批；同一批内连续换词不再逐词请求。
- 加载中保留目标词和 8 个骨架；加载完成后 8 个节点整体 150ms 渐入。换词不再重挂整张纸。
- 9 个节点都可交互：目标词点击按当前模式判定并朗读单词；8 个外围句子点击朗读整句，不改变判定。
- 目标词和九宫格共用同一个 `session.cursor`。从九宫格第 3 页切过来停在第 73 个词；关联辅助推进到第 74 个词再切回九宫格，从第 74 个词继续。
- 关联页保留“会了 / 不会”按钮，判定写到同一个词和同一天，不自动把目标词标成会。
- 目标词没有关联数据时显示空态，不阻塞扫词；当前内置词书已无缺失。

## 体验边界与异常状态（2026-11-08 头脑风暴，待立 AC）

### 进入与初始化

- 首次进入显示今日目标词数和预计页数，不让用户面对一个数字没有预期。
- 初始词书没有释义时，标不会仍显示“暂无释义”，设置里说明释义数据待补。
- 没有任何会词时，关联辅助仍从当前词书的词开始取，不因熟词为空而不可用。

### 每日边界

- 本地日期在页面加载时确定。跨过零点后继续当前标签页仍算前一天，刷新或重新进入才进入新一天。
- 新一天建立全量首轮。未完成的昨天保留为记录，不进入今天的学习流。
- 切换预置词书不改变另一本词书当天的目标词条。

### 页面与提交

- 点击立即改变状态并保存。刷新恢复本页未提交的点击。
- 只有点“下一页”才提交本页并推进轮次。
- 回到上一页会清空该页已提交的判定，需要重新判断。只能回退一页。
- 同一浏览器多个标签页同时学习时，检测到另一标签写入就提示刷新，不静默覆盖进度。
- 切换词书或模块前，本页未提交的点击自动保存。
- 关闭或离开页面不弹确认。已保存的点击和本页位置自动保留。

### 词条与判定

- 超长词条最多两行，超出时降字号，不用省略号截断。
- 词性标记和重复括注在显示时清洗，原始文本保留。
- 同一清洗词形共享一条会或不会状态，跨词书一致。重复词条仍按目标词条计数。
- 中文在英文上方，占固定高度，标不会时显示，格子不移动。
- 再次点击同一词条取消判定。Shift 或触屏切换按钮执行反向判定。
- 触屏提供常驻的“点会 / 点不会”切换，不依赖 Shift。
- Enter 提交本页并翻页。Escape 退出禅模式。
- 点击词条播放美式发音，标会和标不会都播放。快速连续点击只播放最后一次，设置可以静音。

### 状态与反馈

- 判定、翻页和发音失败都在 100 毫秒内给出视觉反馈。
- 状态不只靠颜色，同时有文字和 aria 名称。
- 系统开启减少动态效果时，关闭抽纸和翻页动画。

### 关联辅助

- 目标词补不满 8 条可验证关联时显示空态，提供返回扫词，不用弱关系或编造句子凑数。
- 关联页一页一组 1:8。窄屏纵向排列。
- 关联页只读，不提供判定按钮。返回扫词后停在原页。
- 句子和词节点一起移动。外围位置可以随机。
- 关联内容缺失或加载失败时显示空态，不阻塞扫词。

### 统计与记录

- 每天保存日期、目标数、首轮会、轮次数、是否完成和清零耗时。
- 未完成的一天也保留在学习记录里。
- 统计只使用“本次自评”语义。
- 登录后记录在账号，未登录只在本机。

### 数据与容错

- 本机缓存损坏时从账号重新拉取。未登录时回到初始词书并提示，不覆盖还能读出的数据。
- 本机缓存空间不足时提示并从账号读取，不清空账号历史。
- 只保存当前词状态和每日聚合，不保存逐词长历史。
- 设置里只有“重置今天这本书”，不提供清空全部。

## 非目标与后续讨论

本阶段不固定词库供应商、词向量模型、句子生成模型的具体选型、长期间隔复习算法、自动释义质量或“掌握”阈值。不做词库管理页、统计仪表盘、打卡、排行和社交。不提供导入、导出和清空全部，也不新增自定义词书导入。关联内容进入实现前必须单独解决来源、版权、生成质量、失败回退和用户编辑权。REQ-VOCABULARY-009、REQ-VOCABULARY-010 和 REQ-VOCABULARY-011 已完成规格确认并进入当前工作台实现；窄屏、平板和不同系统缩放仍需持续做浏览器验收，其中移动端浏览器验收按 2026-11-08 用户决定暂缓。
