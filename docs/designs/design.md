# 视觉设计：当前模板事实与白纸英语目标

> 文档状态：定稿

## 当前实现事实

首页和 `/vocabulary` 已经进入词汇白纸模块：A4 白纸、米灰画布、黑字、浅绿/浅红状态、九宫格扫词和低干扰工具栏由 `src/modules/vocabulary/components/vocabulary-screen.module.css` 实现。默认模式和禅模式共用 `PaperSurface`、`ScanGrid` 和 `WordButton`，因此纸张材质、九宫格语义、词格状态和进场动效来自同一套组件。已判断词的状态色和 hover 反馈也由同一套状态规则提供；禅模式不得用额外的中性 hover 规则覆盖已判断词的颜色。禅模式每张纸固定为 6×6 方格，内部是四个 3×3 九宫格；视觉布局使用统一的 6×6 网格，四个九宫格保留语义分组但不占用独立轨道，所有词格横向、纵向复用同一个间距，避免中间缝、两侧缝或组间 hover 背景异常。词格和纸张都保持由方格决定的近正方形比例，完整词条通过换行显示，不使用界面添加的截断省略号，词库原文自带的标点保留。纸张布局按可用面积和方格尺寸计算，窄高度时减少列数以填满视口，不用剩余行高拉伸纸张。旧模板的 dashboard 和任务示例仍保留在迁移边界内，不能被误认为第一阶段产品入口。

## 白纸英语目标

白纸英语采用“纸张是主界面”的视觉方向：

- 页面背景是温和米白，学习区域是略亮的纸张色，正文以黑字为主。
- 层级靠留白、细线、纸张边界和排版表达，不依赖 SaaS 卡片堆叠、渐变或大阴影。
- 词汇状态用低饱和浅绿/浅红，同时显示“会 / 不会”文字、按钮状态和可访问名称。
- A4 是当前活动纸的完整扫描单元。纸摞是导航隐喻，不要求真实三维效果；当前纸上的全部词条必须在用户打开产品的视口内从上到下可见。
- 深色模式是“深纸”而不是蓝黑后台：降低亮度，保留黑字/纸张的阅读关系。
- 视觉不提前加入 AI 光效、成长徽章、掌握分数或课程化进度条。

## 目标令牌

| 令牌                  | 目标方向      | 用途                     |
| --------------------- | ------------- | ------------------------ |
| `--scheme-primary`    | 近黑色        | 主要操作、焦点和标题     |
| `--scheme-background` | 米白纸张      | 页面背景                 |
| `--scheme-card`       | 暖白          | 白纸区域和必要弹层       |
| `--scheme-foreground` | 黑褐色        | 正文和词条               |
| `--scheme-muted`      | 灰褐色        | 说明文字，不承担唯一语义 |
| `--scheme-border`     | 浅灰米色      | 纸张边缘、分隔线和输入框 |
| 状态绿                | 浅绿 + “会”   | 本轮自评为会             |
| 状态红                | 浅红 + “不会” | 本轮自评为不会           |

## 页面与交互约束

- 首页第一屏直接是词汇学习纸，而不是访问仓库或进入模板介绍。
- 第一阶段工作台直接是词汇学习纸；写作和语法可以进入页面外壳，但必须明确标记为暂未开放，不显示虚假的学习结果。三种模块通过独立活动纸切换，不纵向拼成一张长页面。
- 词汇模式通过多本词书纸摞选择当前活动纸；语法模式按低级、中级和高级显示未开放的入口；写作模式显示自由写作纸的页面外壳，但暂不开放输入和保存。
- 当前实现是本地优先且无需登录；账户同步仍是后续边界，不在本轮页面承诺。
- 词汇页面处理 loading、空词库、导入失败、导出和损坏 localStorage 恢复。
- 触屏按钮最小可触达尺寸不依赖 hover；键盘操作有焦点环；颜色状态有文本和 aria 语义。
- 认证面板保留 Better Auth 的登录/注册行为，但文案和视觉使用白纸英语，不再使用 Ignite 宣传语。

## 目标验收

- AC-DESIGN-001：Given 首页未登录访客，When 进入产品，Then 第一视觉就是词汇白纸并能直接开始学习。
- AC-DESIGN-002：Given 词汇判断状态，When 用户使用鼠标、键盘或触屏，Then 会/不会可达、可读并不只依赖颜色。
- AC-DESIGN-003：Given 390px、768px 和桌面宽度，When 用户打开当前 A4 活动纸，Then 纸张中的全部词条在同一视口内从上到下可见，页面没有横向溢出，也不依赖滚动、拆页或展开。
- AC-DESIGN-004：Given 登录或同步失败，When 用户继续学习，Then 本地纸张和已输入内容仍可继续使用，并明确说明失败。

词汇白纸的当前实现、浏览器验收和本轮 Plan 已经对应；全局旧模板主题与后续账户同步仍需另立 Plan 处理。

- DES-DESIGN-101：当前纸张视觉、状态表达和响应式布局事实以本编号引用。

## 事件与命令

| 已发生的变化     | 发起变化的请求           | 责任者           | 规则或策略                           | 后续变化           | 分歧和热点                 |
| ---------------- | ------------------------ | ---------------- | ------------------------------------ | ------------------ | -------------------------- |
| 用户切换学习模式 | 用户点击工作台入口       | 工作台与词汇模块 | 共享纸张、状态和布局约束             | 活动纸内容切换     | 组件是否仍保持同一状态     |
| 视口尺寸变化     | 浏览器 resize 或设备旋转 | 纸张布局         | 先保证完整可见，再调整纸张数量和间距 | 重新计算活动纸布局 | 窄高度下是否出现空白或溢出 |
